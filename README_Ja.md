# 明日方舟（アークナイツ）電子通行認証 PCB

<p align="left">
   <a href="./README.md">简体中文</a> | <strong>日本語</strong>
</p>

スマホゲーム『明日方舟（アークナイツ）』に登場する通行認証を模した電子ネームタグ。

現在のバージョン：Ver0.6

本プロジェクトには通行認証のPCB回路設計が格納されています。PCBレイアウトはコミュニティメンバーの「你说得对」氏がEasyEDA Proを使用して作成しました。

USB配線は私のKiCad設計よりも優れており、2層基板のみで構成されています。元のKiCad設計ファイルを確認したい場合は、左上のブランチを `onlykicad` に切り替えてください。

設計パラメータ：JLCPCBの2層基板仕様に準拠、設計板厚1mm。

## ファイル

* RCパッケージ 0402：
  * ProDoc__v0.6_0402_2026-01-24.epro2 PCB設計ファイル
  * InteractiveBOM_0.6_0402_2026-1-24.html インタラクティブBOM

* RCパッケージ 0603：
  * ProDoc__v0.6_0603_2026-01-24.epro2 PCB設計ファイル
  * InteractiveBOM_0.6_0603_2026-1-24.html インタラクティブBOM


**最新のEasyEDA Proで開いてください。意味がよく分からない場合は 0603 を選んで発注（基板作成）してください。**
